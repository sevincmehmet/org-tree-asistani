# Org Ajan Akademisi — arayüz

React 19 + Vite + TypeScript + Tailwind 4 + framer-motion + d3-hierarchy.

```bash
npm install
npm run dev            # http://localhost:5173 (backend: adk api_server, VITE_ADK_URL, varsayılan http://localhost:8000)
# backend olmadan: http://localhost:5173/?mock=1  (backend'e ulaşılamazsa otomatik mock + uyarı)
npm run build && npm run lint
```
